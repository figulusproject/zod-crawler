# @zod-crawler/web-demo

[![CI](https://github.com/figulusproject/zod-crawler/actions/workflows/ci.yml/badge.svg)](https://github.com/figulusproject/zod-crawler/actions/workflows/ci.yml)

> _Everyone has the right to resist occupation._

A browser-only version of [`@zod-crawler/web`](https://zodcrawler.figulus.dev/docs/#/web)'s UI. The same crawl pipeline runs in a Web Worker in your browser instead of on a server - nothing is uploaded, and a crawl doesn't survive a page refresh.

## Usage

Try it live at [zodcrawler.figulus.dev/demo](https://zodcrawler.figulus.dev/demo), no install required.

See the [docs site](https://zodcrawler.figulus.dev/docs/#/demo) for how direct, browser-side fetches fall back to a CORS proxy, and when to reach for the self-hosted [Web](https://zodcrawler.figulus.dev/docs/#/web) app instead.
